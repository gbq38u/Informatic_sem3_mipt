для защиты от зависания ожидание семафора выполняется с флагом IPC_NOWAIT

программа периодически проверяет доступность хода и состояние второго процесса

в разделяемой памяти сохраняются текущий владелец хода его pid и номер следующего терминала

команда --status показывает значения семафоров и состояние процессов

если процесс завершился не передав ход команда --repair имя передаёт ход работающему терминалу

для синхронизации используются два семафора по одному для каждого процесса

операция -1 заставляет процесс ожидать своего хода а операция +1 передаёт ход другому процессу

в разделяемой памяти хранятся общее число имена процессов их pid текущий владелец и номер следующего процесса

процессы по очереди уменьшают общее число на единицу и выводят результат со своим именем

после достижения нуля первый процесс запрашивает новое число и запускает следующий круг

вместо нового числа можно ввести quit после чего оба процесса завершаются

команда --status показывает общее число значения семафоров владельца хода и состояние процессов

команда --hang имя отправляет процессу SIGSTOP и создаёт искусственное зависание для проверки программы

команда --resume имя отправляет процессу SIGCONT и продолжает работу остановленного процесса

команда --repair имя принудительно передаёт потерянный ход указанному работающему процессу
