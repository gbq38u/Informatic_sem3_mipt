программа не создаёт отдельный файл с сообщениями на диске

после ввода номера комнаты программа получает доступ к общей области разделяемой памяти

пользователи с одинаковым номером комнаты работают с одной и той же областью памяти

в этой памяти хранится список пользователей и отдельная очередь сообщений для каждого из них

при отправке программа находит получателя и помещает сообщение в его очередь

дочерний процесс получателя извлекает сообщение из очереди и выводит его на экран

для защиты памяти используется семафор поэтому несколько программ не могут одновременно изменять общие данные

после чтения сообщение удаляется из очереди

разделяемая память существует отдельно от файла chats.c и может оставаться в системе после завершения программы
